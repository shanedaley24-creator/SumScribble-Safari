SumScribble Safari test

1. Create a PUBLIC GitHub repository named sums-safari-test (or use an existing public repository).
2. Extract this ZIP and upload index.html at the ROOT of the repository.
3. GitHub repository Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. After deployment, open https://YOUR-USERNAME.github.io/sums-safari-test/ in Safari.

Note: Public GitHub Pages exposes the game HTML source. Use a separate public test repository if your iOS source repository is private.
